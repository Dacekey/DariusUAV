# MISSION 01: Launching a demo simulation experiment for CloviX UAV

`reference:` vaults/brainstorm/BS01_26.07.16_Silumation_Missions.txt

## I./ Demo Target
- UAV quadrotor tự động cất cánh, bay qua một chuỗi waypoint, thực hiện một vòng tuần tra, quay về và hạ cánh trong môi trường Gazebo; toàn bộ trạng thái được theo dõi trên QGroundControl.

#### Luồng hệ thống:
```
QGroundControl
      │
      │ MAVLink
      ▼
PX4 SITL ───────── Gazebo
Autopilot           Physics + UAV + World
```

Note: Chưa cần ROS 2, Computer Vision hoặc Offboard Control ở phiên bản đầu. Những phần đó nên là mức nâng cấp sau khi mission bằng QGroundControl chạy ổn định.

---
## II./ Experiment Phases:
### Phase 1: Bay thủ công tối thiểu

Trước khi tạo mission tự động, hãy kiểm tra UAV có thể arm và cất cánh.

Trong QGroundControl:
```
Mở Fly View.
Chọn Takeoff.
Đặt độ cao khoảng 5 m.
Xác nhận thao tác.
Quan sát UAV cất cánh và giữ vị trí.
Chọn Land để hạ cánh.
```

Mục đích của bước này là kiểm tra:
```
PX4 nhận lệnh MAVLink.
Mô hình UAV hoạt động đúng.
Position estimate hợp lệ.
QGroundControl điều khiển được PX4.
Gazebo đang chạy physics bình thường.
```

### Phase 2: Tạo mission tự động

QGroundControl có Plan View để tạo mission, upload mission xuống PX4, sau đó chuyển sang Fly View để chạy mission.

Tạo mission đơn giản gồm:

```
Takeoff: 10 m
    ↓
Waypoint 1
    ↓
Waypoint 2
    ↓
Waypoint 3
    ↓
Waypoint 4
    ↓
Return To Launch
    ↓
Land
```

**Thông số đề xuất:**
```
Độ cao bay: 10–15 m.
Khoảng cách waypoint: 20–40 m.
Tốc độ: 3–5 m/s.
Số waypoint: 4–6.
Khu vực bay: gần vị trí xuất phát.
Kết thúc: Return to Launch hoặc Land.
```

Trong QGroundControl:
```
Chọn Plan.
Chọn vị trí cất cánh.
Thêm Takeoff.
Thêm 4 waypoint tạo thành hình vuông.
Thêm Return hoặc Land.
Nhấn Upload.
Chuyển sang Fly.
Chọn Start Mission.
```
QGroundControl hỗ trợ các mission item như Takeoff, Waypoint, ROI, Return và Land; mission cũng có thể được lưu thành file plan để sử dụng lại.

## III./ Real Demo 

#### Name: Square Autonomous Inspection Mission
**Kịch bản:**
```
UAV cất cánh lên 12 m.
Bay theo hình vuông quanh một khu vực.
Dừng ngắn tại từng waypoint.
Quay về vị trí xuất phát.
Tự động hạ cánh.
```
Đây là demo đơn giản nhưng thể hiện được đầy đủ:
```
Flight controller.
Mission planning.
MAVLink communication.
Autonomous navigation.
Simulation physics.
Ground control monitoring.
```
