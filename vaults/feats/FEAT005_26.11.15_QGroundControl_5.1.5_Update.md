# FEAT005: Cập nhật QGroundControl từ v5.1.3 lên v5.1.5

- **Mã tính năng (ID):** `FEAT005`
- **Ngày cập nhật:** `26.11.15` (2026-11-15)
- **Hệ thống:** Ubuntu 26.04.1 LTS, QGroundControl AppImage x86_64 chạy trên host.
- **Phạm vi:** cập nhật QGroundControl (QGC); Gazebo, PX4, ROS 2 và các script mô phỏng không được thay đổi trong đợt này.

## 1. Phiên bản cũ và mới

| Mục | Trước cập nhật | Sau cập nhật |
| --- | --- | --- |
| Phiên bản QGC đang được alias `uav_qgc` gọi | **v5.1.3** | **v5.1.5 stable** |
| File đang chạy | `apps/QGroundControl-x86_64.AppImage` | `apps/QGroundControl-x86_64.AppImage` |
| SHA-256 của AppImage | `ca0822ef5c502824bcc622ef29e8a8ca265261becceea7e2754e62abaaeabbfc` | `9a47e4cf269d9e4f897f582f6b19aa7ebf1e9e67c9d68a532a45b541354bc344` |
| Bản sao để quay lại | File cũ được giữ ở `apps/QGroundControl-x86_64-v5.1.3.AppImage` | File mới là bản chính |

Phiên bản cũ/mới được đọc trực tiếp từ metadata `<release version>` bên trong từng AppImage. GitHub đánh dấu [v5.1.5 là bản **Latest** và **Stable**](https://github.com/mavlink/qgroundcontrol/releases/tag/v5.1.5). Con số `v5.0.8` trong tài liệu QGC tháng 7 là phiên bản của giai đoạn trước, **không phải** AppImage đang dùng ngay trước lần cập nhật này.

## 2. Cách cập nhật và kiểm tra

1. Kiểm tra AppImage cũ: metadata ghi `5.1.3`.
2. Lấy AppImage Linux x86_64 từ [release chính thức v5.1.5](https://github.com/mavlink/qgroundcontrol/releases/tag/v5.1.5).
3. So SHA-256 của file tải với `sha256:9a47e4cf269d9e4f897f582f6b19aa7ebf1e9e67c9d68a532a45b541354bc344` do GitHub Release API công bố: **khớp**.
4. Kiểm tra AppImage mới là file ELF x86_64, kích thước `195332600` byte; metadata ghi `5.1.5`.
5. Đổi tên bản cũ thành `apps/QGroundControl-x86_64-v5.1.3.AppImage`, đặt bản mới tại `apps/QGroundControl-x86_64.AppImage` và giữ quyền thực thi. Alias `uav_qgc` tiếp tục gọi đúng file chính qua `scripts/run_qgroundcontrol.sh`; không cần đổi lệnh chạy.

**Trạng thái kiểm nghiệm:** bản tải về đã qua kiểm tra checksum, kiến trúc và metadata. Chưa có bài test giao diện, kết nối PX4 hoặc nhiệm vụ bay sau khi thay file trong phiên này; cần xác nhận trong lần chạy mô phỏng tiếp theo.

## 3. Điểm mới và sửa lỗi so với v5.1.3

`v5.1.4` và `v5.1.5` là các bản vá của nhánh **5.1**, tập trung sửa lỗi và cải thiện tính ổn định. Không có một bộ tính năng lớn mới tách biệt khỏi v5.1.3 trong release notes của hai bản này.

| Mảng | Thay đổi đáng chú ý |
| --- | --- |
| Video và camera | v5.1.4 cải thiện ghi hình H.265 (xử lý luồng và ghi trễ); v5.1.5 hiển thị cài đặt receiver cho stream được phát hiện, sửa nút shutter kích hoạt timelapse và tránh gửi lại lệnh zoom khi camera báo giá trị zoom. |
| PX4 và điều khiển bay | v5.1.4 nhận diện gripper theo `PD_GRIPPER_TYPE` trên PX4 v1.17+, chỉnh nhãn PX4 tuning/video, bỏ mục UAVCAN ESC cũ trong Power setup; sửa bán kính GoTo/loiter trong Fly View và nhịp cập nhật joystick. |
| Mission và giao diện | v5.1.4 sửa Save as... của Plan View và cache đoạn đường bay; v5.1.5 khôi phục mission commands bị mất vì lỗi enum dịch thuật, sửa popup thông báo quan trọng chiếm keyboard focus. |
| Kết nối và log | v5.1.4 sửa dọn luồng kết nối khi thoát; v5.1.5 sửa trạng thái kết nối, timeout ban đầu trên đường truyền chậm, đường dẫn MAVFTP, tải onboard log 0 byte và một số lỗi giao diện Settings. |

Các mục trên được tóm tắt từ [release notes v5.1.4](https://github.com/mavlink/qgroundcontrol/releases/tag/v5.1.4) và [v5.1.5](https://github.com/mavlink/qgroundcontrol/releases/tag/v5.1.5). Chúng là thay đổi của QGC; không đồng nghĩa mọi tính năng camera/PX4 trong mô phỏng hiện tại đều đã được kiểm thử sau cập nhật.

## 4. Cách chạy và quay lại khi cần

Lệnh chạy vẫn như cũ:

```bash
uav_qgc
```

File cũ còn ở `apps/QGroundControl-x86_64-v5.1.3.AppImage`. Nếu cần quay lại, dừng QGC rồi đổi tên hai AppImage trong `apps/` để file v5.1.3 nhận lại tên `QGroundControl-x86_64.AppImage`. File `.bak` cũ hơn đã có từ trước và không bị ghi đè trong đợt này.
