## 🧭 TỔNG QUAN HỆ THỐNG VISUAL SLAM
Một hệ thống Visual SLAM (Simultaneous Localization and Mapping) tiêu chuẩn luôn được chia thành **4 khối cốt lõi**:

```
+-------------------------------------------------------------------------------+
|                                 SENSORS DATA                                  |
|                      (Monocular / Stereo / RGB-D / IMU)                       |
+-------------------------------------------------------------------------------+
                                        |
                                        v
+-------------------------------------------------------------------------------+
|                         FRONTEND (VISUAL ODOMETRY)                            |
|  - Feature-based (ORB/SIFT) hoặc Direct Methods (Optical Flow)                |
|  - Ước lượng chuyển động thô (2D-2D Epipolar, 3D-2D PnP, 3D-3D ICP)           |
|  - Trích xuất Keyframe & Local Mapping                                        |
+-------------------------------------------------------------------------------+
                  |                                             |
   Keyframes &    |                                             | Keyframes &
   MapPoints      v                                             v Landmarks
+------------------------------------+       +----------------------------------+
|        BACKEND OPTIMIZATION        |<------|      LOOP CLOSURE DETECTION      |
|  - Bundle Adjustment (BA)          | Loop  |  - Bag-of-Words (DBoW3)          |
|  - Pose Graph Optimization (g2o)   | Info  |  - Phát hiện quay lại chỗ cũ     |
|  - Khử sai số tích lũy (Drift)     |       |  - Khởi tạo tối ưu toàn cục       |
+------------------------------------+       +----------------------------------+
                  |
                  | Global Optimized Poses & Points
                  v
+-------------------------------------------------------------------------------+
|                               MAPPING (BẢN ĐỒ)                                |
|  - Sparse Map (Bản đồ thưa - định vị)                                         |
|  - Dense Map / Point Cloud / OctoMap / TSDF Mesh (Điều hướng, tránh vật cản)  |
+-------------------------------------------------------------------------------+
```

    *   **Kỹ năng đạt được:** Đạt đến trình độ có thể tự thiết kế, đọc hiểu và chỉnh sửa các open-source SLAM hàng đầu thế giới (ORB-SLAM2/3, VINS-Mono, SVO).

*   **Tuần 13+: Xu hướng SLAM hiện đại & Định hướng phát triển (Chương 14)**
    *   **Visual Inertial Odometry (VIO):** Kết hợp Camera + IMU (VINS-Mono, OKVIS, ORB-SLAM3). Tightly-coupled vs Loosely-coupled, IMU Preintegration.
    *   **Semantic SLAM & Deep Learning:** Nhận dạng vật thể (YOLO / Segment-Anything) kết hợp SLAM để loại bỏ vật thể chuyển động (Dynamic SLAM) và hiểu ngữ nghĩa môi trường.
    *   **Lidar-Visual-Inertial SLAM:** LVI-SAM, Fast-LIO2 (hướng đi mạnh mẽ nhất hiện nay cho robot tự hành và drone bay ngoài trời).

Để biên dịch và chạy toàn bộ mã nguồn trong repository này trên Linux (Ubuntu 20.04 / 22.04), bạn cần chuẩn bị các công cụ sau:

| **Đánh giá & Đo lường** | [evo](https://github.com/MichaelGrupp/evo) | Công cụ Python vẽ biểu đồ và tính sai số ATE/RPE |
